# Example data

Sanitized demo data — public CV bullets + a handful of public postings — used for README screenshots and CI. Structurally identical to a real user's `data/user/` (see the vacancy record format in the maintainer's project plan), just fictional/public content. Populated in M2.

Real personal data (yours or the maintainer's) never lives here — it's bind-mounted from your own separate git repo into the gitignored `data/user/`.
